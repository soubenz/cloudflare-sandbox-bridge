        How this console works
        
    
        A lab is a real container. Four things are worth knowing before you start one.
        
    
        
      
        
        
        Brief, terminal and editor
        
        
        Every lab opens on its Brief, which says what you are asked to do. Work in the Terminal, or open a file from the Workspace list in the Editor and save it with Ctrl S.
        
      
        
      
        
        
        Checks
        
        
        Checks are graded and you can re-run them as often as you like. Each carries a weight, and your score is the weighted share that passes. A failing check says why.
        
      
        
      
        
        
        Hints
        
        
        Hints unlock on a timer. The ones still to come are listed as locked, each with a countdown; there is no way to open one early.
        
      
        
      
        
        
        Pressure
        
        
        Some labs change under you around a stated minute. The checks run against what is true at the end, not against what was true when you started.
        
      
        
    
        
    
        Timers. The header counts down to a hard limit, and a lab left alone ends after a warning. End with a snapshot to keep your work and pick it up again.
        
    
        
      
      
    
        
  
        
        



  
        
    
        End this session?
        
    
        The container is destroyed when the session ends. Save a snapshot first if you want to pick this work up again.
