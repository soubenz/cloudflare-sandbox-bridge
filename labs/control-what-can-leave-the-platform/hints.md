# Hints

This lab's hints are delivered on a timer as you work (around the 15%,
30% and 45% marks of the 90-minute session), each as a `hint` event in the
session's own event stream -- see `manifest.yaml`'s `hints:` list for their
exact timing and text. Nothing here is withheld from you on purpose; it's
just that this file is shipped into your workspace at minute zero, before
any of them would actually be useful, so printing them here too would only
spoil the staging.

If you want a nudge before the first one fires: start by running
`agent/agent.py` against both tools and watching the **view** tab while
you do.
