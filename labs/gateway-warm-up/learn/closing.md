Three months later, it's Saturday, three in the morning, and OpenAI goes down again. This time Tomasz's phone stays dark, and he sleeps right through it.

Here is what changed. Larkfield's apps no longer call providers directly. They all call one door, a gateway. It checks who is asking and holds the keys for every provider, so the apps never do. Ollie: "So I can't paste a key I never had. Got it."

Follow the support assistant's call through that night. It asks for support, not for a model. That name is an alias, Larkfield's own name for a job. The gateway looks it up in its table.

The table says OpenAI first, then Anthropic. OpenAI is down, so the gateway quietly sends the call to Anthropic, with the key only it holds. The customer gets an answer.

Anthropic answers, and the gateway writes one line in its log: the team, the alias and the tokens used, one thousand eight hundred and fifty. A token is a small piece of text that providers bill by.

At the end of the month, Graham opens that log. Every row has a team beside it, so the one number on the invoice finally breaks down, team by team. Graham: "Every line has a name. I could get used to this."

And when the next new model comes out, the platform team changes one line in the table. Every app that asks for support gets the new model, and no app changes. Jess: "So I can try the new model today? Today today?"

Next come four short games on what you have just seen. Then the first lab, where you send calls to a real gateway and watch what it does with them.
