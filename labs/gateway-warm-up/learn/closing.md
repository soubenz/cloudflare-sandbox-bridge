Saturday, 3 a.m. Nothing happens. It is the same night as in the story, and the phone beside Tomasz's bed stays dark.

At 03:12 the support assistant's provider goes down, exactly as before. This time the assistant keeps answering, because Larkfield's apps no longer call providers directly. They call one door, a gateway: a service that holds the provider keys, picks the provider for each call and writes down every call. Ollie: "So I can't paste a key I never had. Got it."

Follow one call through it. The support app sends a question with the name support. That name is an alias: Larkfield's own name for a job, not a provider's model name.

The gateway looks support up in its table. The table says which providers and which model support means tonight: provider A first, then provider B. Provider A is down, so the gateway sends the call to provider B.

The gateway adds the provider key, which only it holds, and sends the call on.

Provider B answers. The gateway passes the answer back to the support app, and writes one line in its log: the support team's name, the alias, the provider, and the tokens used, one thousand eight hundred and fifty of them. A token is a small piece of text a provider counts and bills by.

One thing is now easy that was hard before. When a better model comes out, the platform team changes what support points at, in one line of the table. Every app that asks for support moves to the new model, and no app changes. Jess: "So I can try the new model today? Today today?"

Next come four short games on what you have just seen. Then the first lab, where you send calls to a real gateway and watch what it does with them.
